## Cross-check that changed the verdict

The Codex T2 reviewer failed round 0 on a coalescing defect: registration of an in-flight request
happened inside the event handler, so two same-turn refreshes with a repository that completes
synchronously called the repository twice and reported the error twice. Claude Code's T2 passed its
opus review at round 0. An independent opus review of the Claude implementation against that exact
scenario found the same defect, and found that the refactor introduced it: the original page set its
in-flight slot synchronously before returning. The Claude tests never exercised the case (the fake
never completes, every event pair is separated by a queue pump), so green state assertions hid two
repository calls. A fresh tier-3 round (task 6) was run on the Claude branch to fix it with two
regression tests; see the addendum at the end.

## What the run says about the tiers

- Tier 1 at xhigh (Luna) passed the mechanical test at round zero, where Luna at medium needed a
  round the day before; haiku passed at round zero both times.
- Tier 2 at xhigh (Sol) passed the async test at round zero with the discriminating-test criterion
  in the spec; sonnet did too. The criterion, not the tier, is the difference from 2026-09-12.
- Tier 3 as reviewer: Astra low found a behaviour regression in a structural refactor that opus
  missed at round zero; the same defect existed in both implementations. One data point, but it is
  the second time in two days that the integrated-level or tier-3 review found what the per-task
  review did not.
- Orchestrator at high (Astra) caused zero rework rounds, corrected two setup defects in the brief
  and one in the helper script on its own, and proved tree equality; no observable loss against
  xhigh. Fable at high on Claude Code likewise caused zero rounds and accepted one spec inaccuracy
  without charging the implementer.
- Explorers at tier 1 cost more than they saved on Codex (14.1M tokens, mostly cache reads) and
  about 261k on Claude Code; both orchestrators wrote precise specs from them. Whether cheaper
  explorer effort keeps spec quality is the next cell.

## Setup defects found by the orchestrators (fixed in 0.3.1 and 0.3.2)

- Symlinked Codex role files are ignored; the gate stopped the run instead of falling back.
- A worktree prefix containing `/` produced nested directories; branch names in the brief carried a
  tool name against the repository's rule.
- `~/.agents` is sandbox-protected on Codex like `~/.codex`; the run directory moved.
- The dependency-fetch log was written inside each worktree, where `git add -A` would stage it.
